How co-op works
Both players can send commands without waiting for the other. Monsters respond to completed actions; there is no countdown while both players are idle. Taking stairs, falling through a trap, or recalling brings the party to the same new level. Item pickup is first come, first served. Drop an item for your companion to collect. Shops admit one player at a time.
This is an experimental multiplayer adaptation. Exploration and game options are shared. Legacy save files, scores, file export, and wizard mode are not available. Keep this tab to reconnect; refreshing preserves your player. Server restarts lose the room.
